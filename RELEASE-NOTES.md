Macro Tracker 1.4.0 adds a reusable food library, day-specific targets, local nutrition-label recognition, weekly check-ins, and three rounded dashboard themes.

- Library tabs: history, favorites, saved meals, recipes, snacks, and drinks. Copy foods to another date/time, select diary foods to save together, or build a recipe with USDA ingredients.
- Recipes support servings and optional finished batch weight. Logging a saved meal creates independent ingredient entries that remain editable.
- Save named training/rest/custom presets, assign Sunday–Saturday schedules, and apply one-day overrides. Historical target snapshots are preserved.
- Import or paste an English nutrition-label image for on-device Windows OCR. Review the image beside extracted values; ambiguous/missing macros stay blank. Save confirmed results to favorites. Optional fiber/sugar/sodium are stored as notes, not tracked daily nutrients.
- Mark diary days complete. Food changes reopen them. Weekly averages/highest/lowest use completed days; incomplete bars are faded.
- Weekly check-in: average macros, target results, day-type comparisons, weight averages/trend, hunger, energy, workout performance, reflection, and a focus for next week. Targets change only when you edit them.
- Graphite, Purple, and White / Red / Blue themes; independently filling concentric macro rings, arm/wheat/avocado icons, and Sunday–Saturday calorie bars with a dotted target line.
- Add-food preview shows remaining macros after saving.

Use Settings → App updates → Check for updates, then Download update. Your diary and USDA key remain in their existing location. The first library upgrade also creates a database backup.

Label recognition uses installed Windows OCR languages and Windows PowerShell. No cloud AI account or API key is required. If local OCR is unavailable or restricted, paste label text into the same review screen. OCR is imperfect: verify serving basis and numbers before saving. English label extraction currently supports calories, protein, total carbohydrate and total fat; multi-column labels require manual review.

Windows 10/11 x64 and .NET Framework 4.8. Builds remain unsigned.
