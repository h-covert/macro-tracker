Macro Tracker 1.3.0 adds a permanent per-user installation and in-app updates.

- First-time installation: download **MacroTracker-Setup.exe**, exit any older Macro Tracker from its tray menu, and run setup once.
- Future releases: the app checks GitHub when it opens. Click **Download update** to verify, apply, and restart without reinstalling.
- Food history, targets, reminders, favorites, weight entries, and the encrypted USDA key stay in their existing local data folder.
- Includes USDA search, household portions, editable quantity, time eaten, exports, and backup/restore.

Windows 10/11 x64 with .NET Framework 4.8. No administrator access needed for setup. The executable is unsigned.

The ZIP is the portable/app-update package. SHA256SUMS.txt provides release checksums. The in-app updater uses GitHub's SHA-256 asset digest automatically.
